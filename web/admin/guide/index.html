২. Dashboard-এ প্রতিদিন কীভাবে check করবেন

  1. Dashboard menu-তে যান।
  2. উপরে 7d, 30d অথবা 90d বেছে নিন। নতুন shop হলে 30d সবচেয়ে উপযোগী।
  3. Revenue দেখুন—নিশ্চিত/চলমান order থেকে মোট বিক্রি। Pending বা cancelled order এখানে বিক্রি হিসেবে ধরা হয় না।
  4. Orders দেখে বুঝুন কতগুলো order হয়েছে এবং Avg order value দেখে গড় order value জানুন।
  5. Stock on hand, Needs restocking এবং Top Products দেখে কোন product আগে refill করতে হবে ঠিক করুন।

Dashboard-এর সংখ্যা দেখার জন্য; product বা order পরিবর্তনের জন্য Products, Orders অথবা Inventory menu ব্যবহার করতে হবে।

৩. View Mode এবং Edit Mode কীভাবে ব্যবহার করবেন

Dashboard-এর উপরের View Mode ও Edit Mode দিয়ে দেখার কাজ এবং পরিবর্তনের কাজ আলাদা রাখা হয়েছে। ভুল করে live price বা content বদলে ফেলা এড়াতে আগে View Mode-এ check করুন।

Modeব্যবহারProduct page-এ যে action দেখবেন
View ModeLive catalogue দেখে যাচাই করাView live দিয়ে customer-এর product page দেখুন; প্রয়োজন হলে Quick edit চাপুন।
Edit ModeLive shop-এর product তথ্য পরিবর্তন করাEdit দিয়ে পুরো editor খুলুন এবং Stock দিয়ে stock adjustment করুন।
  1. প্রথমে View Mode-এ product name, image, price ও stock দেখুন।
  2. কোনো ভুল পেলে সেই row-এর Quick edit চাপুন। Dashboard নিজে থেকে Edit Mode-এ চলে যাবে।
  3. পরিবর্তন করে Save changes চাপুন। Success message দেখা না পর্যন্ত page বন্ধ করবেন না।
  4. তারপর View live খুলে customer page-এ পরিবর্তনটি ঠিক হয়েছে কি না দেখুন। View Mode storefront-এ product detail page খুললে admin session থাকা অবস্থায় Edit this product in Admin Dashboard link দিয়ে সরাসরি Edit Mode-এ ফিরে আসুন।

৪. নতুন Product কীভাবে যোগ করবেন

  1. Products → Edit Mode → + New product চাপুন।
  2. Product name-এ customer যে নাম দেখবে সেটি লিখুন।
  3. SKU নিজের internal code হলে লিখুন; না জানলে খালি রাখতে পারেন, system code তৈরি করবে।
  4. Category ID-তে নিচের table অনুযায়ী সংখ্যা দিন। Clothing এখন hidden, তাই customer-facing category হিসেবে ব্যবহার করবেন না।
  5. Short summary ও Description-এ সহজ ভাষায় product কী, কত ml/g এবং কীভাবে ব্যবহার করতে হয় লিখুন।
  6. Cost price, Selling price, stock, low-stock threshold, minimum order quantity, weight ও barcode লিখুন।
  7. Primary image-এর জন্য file বাছাই করে Upload primary image চাপুন; চাইলে HTTPS বা /assets/ URL-ও দিতে পারেন। অতিরিক্ত ছবি upload করতে এক বা একাধিক file বাছাই করে Upload gallery images চাপুন। Video-এর জন্য HTTPS URL দিন।
  8. Storefront-এ দেখাতে Status = Active দিন। Draft রাখলে customer product দেখতে পাবে না।
  9. Homepage-এ highlight করতে Feature on homepage tick দিন। সব product-এ এটি tick করার দরকার নেই।
  10. সবশেষে Create product চাপুন এবং Products table-এ productটি দেখা যাচ্ছে কি না check করুন।

৫. Product edit, দাম পরিবর্তন এবং ছবি/video যোগ করা

Products page-এ নাম, SKU বা barcode দিয়ে search করুন। Product-এর row-তে Edit চাপলে পুরনো তথ্য খুলবে। শুধু দাম পরিবর্তন করতে Selling price বদলান; পুরনো দাম দেখাতে Compare-at price রাখুন। তারপর Save changes চাপুন এবং storefront-এ View live দিয়ে যাচাই করুন।

একাধিক ছবি ও video যোগ করার নিয়ম

  1. Primary image URL-এ প্রথম/প্রধান ছবি দিন, যেমন /assets/product-front.jpg।
  2. Additional images and videos box-এ নিচের মতো JSON array paste করুন।
  3. ছবির জন্য type হবে image এবং video-র জন্য video।
  4. ছবির URL অবশ্যই /assets/ দিয়ে শুরু হওয়া repository asset অথবা https:// URL হতে হবে।
  5. Video হিসেবে সরাসরি playable HTTPS video URL ব্যবহার করুন, যেমন MP4/WebM link। Save করার পরে product detail page-এ thumbnail দেখা যাবে।
[{"type":"image","url":"/assets/product-side.jpg","alt":"Side view"},{"type":"image","url":"https://example.com/product-back.jpg","alt":"Back view"},{"type":"video","url":"https://example.com/product-demo.mp4"}]

Direct upload: R2 storage binding active থাকলে dashboard-এর file picker দিয়ে JPG, PNG, WEBP, GIF বা AVIF image সরাসরি upload হবে। Upload শেষ হলে image URL automaticভাবে বসবে; product-এ দেখাতে অবশ্যই Save changes বা Create product চাপুন। R2 এখনও active না হলে button-এ setup message দেখাবে—তখন URL বা /assets/ asset ব্যবহার করা যাবে।

৬. Stock কীভাবে বাড়াবেন বা কমাবেন

Stock পরিবর্তনের জন্য Inventory page অথবা Products table-এর Stock button ব্যবহার করুন। Button চাপলে প্রথমে quantity এবং পরে reason চাইবে।

Reason-এর পরে ছোট note লিখুন, যেমন “Supplier delivery 25 August”। এতে পরে কে, কখন এবং কেন stock বদলেছে বোঝা যাবে। Order বা return থেকে system stock update করলে একই item আবার manually যোগ করবেন না।

৭. Customer Order কীভাবে process করবেন

  1. Orders page খুলুন।
  2. Order code, customer name অথবা phone দিয়ে search করুন। প্রয়োজনে status filter ব্যবহার করুন।
  3. Customer-এর নাম, phone, district/upazila, product, total এবং payment status মিলিয়ে দেখুন।
  4. Customer-এর payment যাচাই করে order status ধাপে ধাপে update করুন।
  5. Courier booking বা shipment-এর পরে courier status check করুন।
  6. Customer-কে update দেওয়ার আগে invoice print করে product, quantity, weight এবং delivery fee মিলিয়ে নিন।
Statusকখন ব্যবহার করবেন
pendingনতুন order এসেছে, এখনো যাচাই হয়নি।
confirmedCustomer/order/payment তথ্য যাচাই হয়েছে।
processingProduct pack বা order প্রস্তুত হচ্ছে।
shippedCourier-এর কাছে দেওয়া হয়েছে।
deliveredCustomer product গ্রহণ করেছে।
returnedProduct ফেরত এসেছে বা return process সম্পন্ন হয়েছে।
customer_cancelled / admin_cancelledCancel হওয়ার প্রকৃত কারণ অনুযায়ী সঠিক status দিন।

৮. Invoice কীভাবে print করবেন

Orders page-এ যে order-এর invoice দরকার, তার পাশে Print invoice চাপুন। Print window খুললে product name, quantity, unit price, weight, total package weight, payment method, order source, delivery fee এবং customer address check করুন। তারপর printer নির্বাচন করে print করুন অথবা Save as PDF বেছে নিন। ভুল থাকলে print করার আগে order তথ্য ঠিক করুন।

৯. Return কীভাবে পরিচালনা করবেন

  1. Returns page খুলুন। requested filter দিয়ে নতুন request দেখুন।
  2. Order code, customer, phone, reason এবং amount মিলিয়ে নিন।
  3. Return গ্রহণযোগ্য হলে approved দিন। Courier pickup হলে picked_up দিন।
  4. Product হাতে পাওয়ার পরে condition check করে received দিন।
  5. টাকা ফেরত দেওয়ার পর refunded দিন। গ্রহণযোগ্য না হলে rejected দিন।

Received status-এর সময় system stock ledger-এ product ফেরত যোগ করে। একই return বারবার update করলে stock double-count হওয়ার কথা নয়; তবুও ledger দেখে নিশ্চিত হোন।

১০. Customer Rating ও Review approve করা

Customer product page-এ ১ থেকে ৫ star rating এবং review দিতে পারবে। তবে review তখনই submit হবে যখন customer-এর purchase system-এ পাওয়া যাবে—account login থাকলে তার account-এর shipped/delivered order থেকে, আর login না থাকলে phone number-এর সঙ্গে Order Number অথবা Invoice Number মিলিয়ে। তাই fake buyer বা product না-কেনা visitor review submit করতে পারবে না।

  1. Admin menu থেকে Reviews খুলুন।
  2. Pending filter নির্বাচন করে নতুন review দেখুন। Product name, buyer name, star rating, review text, Order Number এবং Invoice Number মিলিয়ে নিন।
  3. Review স্বাভাবিক এবং purchase তথ্য সঠিক হলে status Approved দিন অথবা Approve button চাপুন।
  4. ভুল, অশালীন, অসম্পূর্ণ বা সন্দেহজনক review হলে status Rejected দিন। সন্দেহ হলে approve না করে আগে order ও invoice check করুন।
  5. Approved review customer product page-এ প্রকাশ পাবে এবং product-এর average rating ও review count automatic update হবে।

কোনো product-এর approved rating ৪.৫ বা তার বেশি হলে সেটি manual featured না হলেও Top Collection-এ automatic যোগ হওয়ার জন্য eligible হবে। Rating কমে গেলে বা review reject করলে Top Collection eligibility-ও update হবে।

১১. দোকানের POS sale ও barcode

  1. POS & Barcodes page খুলুন।
  2. Barcode scanner থাকলে cursor search box-এ রেখে barcode scan করুন; না হলে product name বা barcode লিখে Find চাপুন।
  3. Product row-তে Add চাপুন। একাধিক item হলে প্রত্যেকটি যোগ করুন।
  4. প্রয়োজনে discount দিন এবং Cash, bKash, Nagad, Rocket অথবা Card payment বেছে নিন।
  5. Receipt preview-এ product ও total মিলিয়ে Complete sale & print receipt চাপুন।

POS sale complete হলে shop stock কমে এবং আলাদা POS হিসাব তৈরি হয়। ভুল sale হলে নিজে থেকে stock কম-বেশি না করে Inventory ledger-এ পরিষ্কার adjustment note দিন।
