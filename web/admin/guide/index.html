১. সাইন ইন

সাইটের শেষে /admin যোগ করে dashboard খুলুন। GitHub Secrets-এ সংরক্ষিত administrator username ও password ব্যবহার করুন। সফল login-এর পর session ১২ ঘণ্টা active থাকবে। কাজ শেষে বাম পাশের Sign out চাপুন।

২. Dashboard

Dashboard-এ ৭ দিন, ৩০ দিন অথবা ৯০ দিনের Revenue, Gross Profit, Orders, Average Order Value, Stock, Restock এবং Top Products দেখা যাবে। Revenue হিসাব confirmed বা পরবর্তী order থেকে গণনা হয়; pending ও cancelled order income হিসেবে ধরা হয় না।

৩. Product যোগ করা

  1. Products → + New product চাপুন।
  2. Product name, SKU, Brand, Category ID, short summary, description, cost price, selling price, stock, low-stock threshold, weight ও barcode লিখুন।
  3. Image URL ব্যবহার করুন; R2 চালু হলে পরবর্তীতে direct upload যুক্ত করা যাবে।
  4. Status হিসেবে Active দিলে storefront-এ দেখা যাবে; Draft দিলে hidden থাকবে।
  5. Feature on homepage tick করলে Best Seller section-এর জন্য product চিহ্নিত হবে।

৪. Stock পরিবর্তন

Inventory অথবা Products table থেকে Stock চাপুন। Positive number দিলে stock বাড়বে, negative number দিলে কমবে। Reason হিসেবে restock, return, damage, adjustment, sale অথবা cancellation দিন। প্রতিটি পরিবর্তন stock ledger-এ actor ও note সহ সংরক্ষিত হবে।

৫. Orders

Orders page-এ order code, customer, phone, total, payment method, courier status এবং current order status দেখা যাবে। Search box বা status filter দিয়ে order খুঁজুন। Steadfast booking ও manual courier status refresh-এর জন্য existing courier console ব্যবহার করুন।

৬. Store Settings

Settings থেকে store name, tagline, support contact, currency, delivery fee, free-delivery threshold, payment numbers, WhatsApp number, tax এবং site description পরিবর্তন করা যাবে। Save করার পর settings পরবর্তী order ও public integration-এ ব্যবহারের জন্য database-এ সংরক্ষিত হবে।

৭. নিরাপত্তা ও গুরুত্বপূর্ণ নিয়ম

  • API token বা password কখনো public message, screenshot বা product description-এ রাখবেন না।
  • Product delete না করে archive করুন, যাতে পুরনো order history নষ্ট না হয়।
  • Customer password বা admin secret dashboard table-এ প্রদর্শিত হবে না।
  • Order return বা cancellation হলে stock manually দুইবার যোগ করবেন না।

৮. বর্তমানে প্রস্তুত ও পরবর্তী modules

বর্তমান dashboard foundation-এ secure login, overview metrics, product catalog management, stock ledger entry, order list এবং store settings রয়েছে। Volume pricing, invoice print, banners, pages, blog, offers, customers, content editor এবং full E2E test modules পরবর্তী implementation batch-এ যুক্ত হবে।
