১. সাইন ইন

সাইটের শেষে /admin যোগ করে dashboard খুলুন। GitHub Secrets-এ সংরক্ষিত administrator username ও password ব্যবহার করুন। সফল login-এর পর session ১২ ঘণ্টা active থাকবে। কাজ শেষে বাম পাশের Sign out চাপুন।

২. Dashboard

Dashboard-এ ৭ দিন, ৩০ দিন অথবা ৯০ দিনের Revenue, Gross Profit, Orders, Average Order Value, Stock, Restock এবং Top Products দেখা যাবে। Revenue হিসাব confirmed বা পরবর্তী order থেকে গণনা হয়; pending ও cancelled order income হিসেবে ধরা হয় না।

৩. Product যোগ করা

  1. Products → + New product চাপুন।
  2. Product name, SKU, Brand, Category ID, short summary, description, cost price, selling price, stock, low-stock threshold, weight ও barcode লিখুন।
  3. Image URL ব্যবহার করুন; R2 চালু হলে পরবর্তীতে direct upload যুক্ত করা যাবে।
  4. Status হিসেবে Active দিলে storefront-এ দেখা যাবে; Draft দিলে hidden থাকবে।
  5. Feature on homepage tick করলে Best Seller section-এর জন্য product চিহ্নিত হবে।

৪. Stock পরিবর্তন

Inventory অথবা Products table থেকে Stock চাপুন। Positive number দিলে stock বাড়বে, negative number দিলে কমবে। Reason হিসেবে restock, return, damage, adjustment, sale অথবা cancellation দিন। প্রতিটি পরিবর্তন stock ledger-এ actor ও note সহ সংরক্ষিত হবে।

৫. Orders ও Invoice

Orders page-এ order code, customer, phone, total, payment method, courier status এবং current order status দেখা যাবে। Search box বা status filter দিয়ে order খুঁজুন। প্রতিটি order-এর Print invoice button থেকে printable invoice খুলবে। Invoice-এ product name, quantity, unit price, weight, package weight, payment method, order source এবং delivery fee থাকবে।

৬. Returns

Returns page-এ customer return request approve, pick-up, receive, refund বা reject করা যাবে। Received status দিলে order-এর stock একবার ledger-এ ফেরত যোগ হবে; একই return আবার update করলে stock double-count হবে না। Failed payment-এর refund status admin-কে যাচাই করে update করতে হবে।

৭. POS ও Barcode

POS & Barcodes page-এ product name, SKU বা barcode scan/search করে in-store sale তৈরি করুন। Payment method নির্বাচন করে discount প্রয়োগ করা যাবে। Complete sale & print receipt চাপলে stock কমবে, POS ledger তৈরি হবে এবং receipt print dialog খুলবে।

৮. Content CMS

Content CMS থেকে homepage topbar banner, delivery/about pages, Journal blog post এবং offer তৈরি বা update করা যাবে। Draft public site-এ প্রকাশ পাবে না; published content public homepage API-তে দেখা যাবে। Clothing category backend-এ তৈরি আছে কিন্তু active নয়, তাই customer storefront-এ hidden থাকবে।

৯. Customer account

Customer /account.html থেকে mobile number ও password দিয়ে account খুলতে বা sign in করতে পারবে। Account থেকে order history, printable invoice এবং delivered/shipped order-এর return request করা যাবে। Password salted hash হিসেবে রাখা হয়; admin panel-এ password দেখা যায় না।

১০. Customer ও Admin AI Chatbot

Storefront-এর নিচের Need help? button চাপলে popup-এ AI support এবং WhatsApp option দেখা যাবে। Customer assistant শুধু product, price, stock, usage, delivery, order, return, payment ও shop policy নিয়ে উত্তর দেবে। WhatsApp button সরাসরি +880 1738-745949-এ যাবে।

Admin-এর Admin Assistant private shop data—stock, orders, returns, POS sales এবং settings context—থেকে operational summary দেবে। এটি password, API key, raw token প্রকাশ করবে না এবং নিজে থেকে irreversible data change করবে না। Default provider Cloudflare Workers AI; Cloudflare AI unavailable হলে configured Gemini key fallback ব্যবহার করবে।

১১. Store Settings

Settings থেকে store name, tagline, support contact, currency, delivery fee, free-delivery threshold, payment numbers, WhatsApp number, tax এবং site description পরিবর্তন করা যাবে। Save করার পর settings পরবর্তী order ও public integration-এ ব্যবহারের জন্য database-এ সংরক্ষিত হবে।

১২. নিরাপত্তা ও গুরুত্বপূর্ণ নিয়ম

  • API token বা password কখনো public message, screenshot বা product description-এ রাখবেন না।
  • Product delete না করে archive করুন, যাতে পুরনো order history নষ্ট না হয়।
  • Customer password বা admin secret dashboard table-এ প্রদর্শিত হবে না।
  • Order return বা cancellation হলে stock manually দুইবার যোগ করবেন না।

১৩. বর্তমানে প্রস্তুত ও পরবর্তী modules

বর্তমানে secure login, overview metrics, product catalog, stock ledger, order operations, invoice print, returns, POS receipt, CMS content, customer accounts, hidden clothing category foundation, customer AI/WhatsApp popup এবং private admin assistant প্রস্তুত। Direct R2 image upload, automated payment gateway/refund settlement, full barcode label printer integration, Messenger/WhatsApp inbound order automation, and complete Playwright regression suite remain as later hardening modules.
